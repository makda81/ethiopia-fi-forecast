# Ethiopia Financial Inclusion Forecasting

## Project Overview

This project builds a forecasting system to predict Ethiopia's financial inclusion indicators – **Access (Account Ownership)** and **Usage (Digital Payment Adoption)** – using historical data and event impact modeling.

**For:** Consortium of stakeholders (DFIs, mobile operators, National Bank of Ethiopia).  
**Goal:** Forecast 2025-2027 outcomes and provide an interactive dashboard.
